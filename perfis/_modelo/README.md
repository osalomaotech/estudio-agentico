# Perfil modelo

Ponto de partida para quem usa a skill pela primeira vez. A entrevista (bloco 3 do `briefing.md`) preenche estes arquivos numa pasta nova, `perfis/<seu-nome>/`.

- `brand.json`: cores, fonte, rodapé, fotos, logo e contato. Os caminhos de foto e logo são relativos à pasta do `brand.json`.
- `regras.md` (opcional): o que nunca pode aparecer nos seus materiais.
- `autoridade.md` (opcional): credenciais e números que você aprova para usar.
- `voz.md` (opcional): como você fala e escreve.
- `brandings/` (opcional): se você usa mais de uma identidade (pessoal, empresa, cliente), crie uma subpasta para cada uma, com o próprio `brand.json` e o próprio `regras.md`. A skill pergunta qual usar a cada material.

O `brand.json` daqui é um tema claro de exemplo, usado no catálogo de layouts.
